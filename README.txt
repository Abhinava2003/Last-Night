LAST LIGHT — LOCAL GAME PACKAGE

HOW TO PLAY
1. Extract Last-Light-Game.zip on your computer or phone.
2. Open index.html in a modern web browser. No installation or server is required.
3. Choose a path with a tap, mouse click, or keyboard keys 1–3.

INCLUDED FEATURES
Branching story and multiple endings; animated 2D scenes and character actions; time, trust, energy, and beacon-charge meters; inventory; route log; live score; persistent best score; and an in-game replay button.

BEST SCORE
The best score is saved in the browser on the device where the game is played. Players sharing that browser/device share its best-score record. The record does not sync across devices.
